# #124 图片缩放与拖动验收

运行 `npm.cmd run dev -- --config scripts/image124/vite.config.ts`，打开 `http://127.0.0.1:1524/scripts/image124/`。

使用真实 MessageList 和附件预览，图片由内存 Canvas 合成，不读取用户数据库、附件文件、凭据或供应商，不调用原生命令。所有交互状态只在内存保留。

检查浅深主题、窄窗口、宽图／长图／小图；缩放 25%–400%、滚轮、拖动边界、适配恢复、窗口调整、切图后重置；Tab 环、图片区域方向键移动、+／−／0、Escape 关闭与原入口回焦，关闭前后的消息滚动位置一致。
