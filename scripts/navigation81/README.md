# #81 隔离导航体验

仓库根目录运行：

```powershell
npx.cmd vite --config scripts/navigation81/vite.config.ts
```

打开 <http://127.0.0.1:1501/scripts/navigation81/index.html>。使用真实 AppShell、ConversationNavigation、ChatWorkspace 和聊天 repository，独立端口源上的 `Navigation81Synthetic` 数据库；不读取日常应用数据库、连接配置或凭据，不发送供应商请求。首次初始化合成助手、长对话列表和消息。右上角可切换主题、合成背景、透明度和模拟生成；设置／绘图入口用于检查导航跨页面记忆，不加载真实页面。

点击头像展开，直接点击聊天正文、空白、输入框或输入工具区收缩；顶部栏、导航、Tab、普通失焦与纯滚动保持原形态，弹层内部与遮罩不触发。开发助手在新初始化的合成库中使用本地生成的 PNG，供助手／对话切换检查图片头像；模型选择器使用空配置，不发送请求。可检查菜单、创建取消、长列表滚动和小屏布局。热更新与文件监听关闭，修改代码后需重启夹具并刷新，以免热更新破坏运行时状态与测量结果。已有合成库不会重建，检查新增图片样例时可用 `--port 1512` 指定新的隔离端口源。

此夹具用于浏览器前端验收。实际桌面体验使用正常 `npm.cmd run tauri dev`，原生窗口交互与主观手感另行验收。

短暂禁用检查包含真实 ChatHeader、附件／思考／搜索入口与消息操作按钮，按会话 ID 重挂载聊天组件以匹配 App。消息操作回调为合成空操作，模型与配置调整也不访问供应商；会话读取和切换使用真实隔离 repository。模拟生成可检查清空、消息操作与删除的持续禁用样式。首次读取和后续命令等待的区分另有确定性 hook 测试，不以浏览器快速启动代替慢读取覆盖。
