# #90 绘图提示词预设与生成参数复用

2026-10-01 按用户确认实施 [#90](https://github.com/AyaseMinami/AyaseStudio/issues/90)。预设只有名称和提示词，存入既有本机数据库；任务／成果历史保留完整可恢复参数，显式带参数 PNG 沿用 #89。本文记录本地实施，不代表已提交、推送或关闭 Issue。

## 实施合同

- 数据库 v8 仅新增 `drawingPromptPresets`。每条记录仅含稳定 ID、名称、正文、创建／更新时间；不绑定模型、连接、参数、参考图或 Key。名称去掉首尾空白，正文原样保留，必填校验不新增长度或重名限制。新增／更新通过字段白名单，更新不存在记录拒绝，不将旧记录重新创建。
- 预设选择直接替换提示词，其余草稿字段保持，不弹覆盖确认、不生成。草稿编辑不自动更改预设。新建／另存从当前文字开始；更新以当前草稿为起点，编辑以已保存内容为起点。弹窗明确保存才写入，取消不写入，失败保留填写内容，阻止重复提交，焦点约束／回焦及背景 inert 保持键盘语义。
- 控制器序列化预设写入并冻结调用时的名称／正文，成功入库后才发布已保存记录。关闭准备等待已开始的预设写入并禁止新命令。读取失败不会按空数据库继续写入。仅有预设也计入绘图数据，旧备份／恢复继续被 #93 前置保护阻断，避免静默遗漏。
- 任务与成果共用现有引用生命周期队列中的参数复用逻辑。直接恢复提示词、原目标模型、对应协议参数、有序参考图描述；另一个协议的独立草稿参数保留。目标失效保留可恢复文本和原协议控件，要求重新选择；参考文件读取失败逐项提示，不宣称完整恢复。复用不修改历史、不创建任务、不调用供应商。
- 任务／成果复制只写剪贴板，不载入草稿、不生成。普通 PNG 无生成元数据，显式参数 PNG 保持 #89 的脱敏白名单；不新增 JSON 副文件或旧 PNG 导入。

## GNBP 依据与差异

核对固定桌面版本 `0c07f22a3f7c2762cd0584ff702ceae7b9e07e09` 的 [config/config_mgr.py](https://github.com/AyaseMinami/gnbp-image-generator/blob/0c07f22a3f7c2762cd0584ff702ceae7b9e07e09/config/config_mgr.py)、[ui/main_window.py](https://github.com/AyaseMinami/gnbp-image-generator/blob/0c07f22a3f7c2762cd0584ff702ceae7b9e07e09/ui/main_window.py) 和 [core/utils.py](https://github.com/AyaseMinami/gnbp-image-generator/blob/0c07f22a3f7c2762cd0584ff702ceae7b9e07e09/core/utils.py)。桌面预设仅名称／内容，选择直接载入，生成配置写 PNG `parameters` 元数据；参考图元数据仅文件名，API Key 被移除。Ayase 借鉴行为，在自身 Dexie 仓库存储预设，历史复用按已批准需求恢复有序私有引用，不照搬部分字段回填或 Python 实现。未复制 GNBP 代码或素材。
