## 生命周期与恢复

- `queued → preparing → dispatching → running → saving`：发送前耐久写入 `dispatching`；`running` 为已进入本地调用的显示阶段。重启不会自动重发这两类可能发送项。发现本地结果日志时优先恢复；准备项恢复为 queued，等待项暂停。
- 取消等待／准备项不发请求；运行取消结束本地等待，结果未知，不承诺远端取消／免计费。即使适配器忽略 abort，迟到响应也不能再次提交结果。进入保存后的取消不破坏图片落盘。
- 收到图片后，即使 saving 状态的 DB 更新失败，也继续尝试图片落盘。原生 pending 清单保持图片序号、内容摘要与固定文件 ID；manifest 和 DB 完成均可幂等恢复。未写入耐久字节前的崩溃窗口不能恢复，明确展示而不自动重新生成。
- 新增恢复盘点接口：逐图区分耐久、仅内存及已丢失；日志损坏／读取失败显示未核实，保留文件。已耐久图片立即释放内存副本，部分失败仅保留缺失图片；本地保存重试依据原日志摘要补缺项，不调用供应商。全部字节耐久而 manifest／DB 失败时无需保留完整响应。
- 连暂存也失败时继续派发，并保留仅内存图片直到本地保存成功、用户确认删除该任务，或确认放弃后退出。没有自动逐出、隐式丢图或新增暂停规则；磁盘完全不可写时内存仍可能随任务数增长。本轮包含连续失败与释放路径离线回归，真实大图压力、资源指标和可用容量属于 #94 验收，不能把合成小图测试当成已验证内存上限。

## 任务管理与所有权

单项／批次／全部取消与暂停派发独立。任务页支持单条删除、清空已完成历史、清空失败／取消／未知／保存失败历史。删除只接受终态；未知结果说明不撤销远端生成或计费，保存失败列出将放弃恢复的图片序号。取消确认不修改任务；已保存成果保持。

重新生成创建独立 ID、批次和不可变参数副本，并保存 `sourceTaskId`。同次进行中的登记及同源未结束替代任务复用 ID；替代完成后的新动作可再次创建。未知结果重新生成提示重复生成／计费风险。源任务删除不影响替代任务及其输入所有权。

历史管理与参考图变更共用生命周期串行链；删除同步保留该任务的操作锁，与本地保存重试互斥。数据库仅由 enqueue 新建任务，saveTask／complete 在事务内拒绝不存在的任务；删除事务拒绝活动项。已删除记录不会被迟到更新复活。

DB 删除完成后释放该任务的内存响应；只在没有成果、草稿或其他任务拥有对应输出资源时清理该任务日志与文件。成果继续独立持有输出和输入引用。原生清理只接受合法私有任务 ID、清单中的路径，校验链接和目录，不递归扫描删除。清理失败保留文件并显示错误；若进程恰在 DB 删除后、文件清理前退出，可能遗留无主文件，但不会恢复为任务或自动发请求。本切片不做全盘孤儿文件扫描。

## 诊断与边界

诊断仅存允许的类别和 HTTP 状态：服务拒绝、限流、网络未知、无效响应、本地文件、本地记录、配置及取消。任务页显示可理解的中文原因；不收集原始 HTTP 正文、Key 或机器路径。原协议请求格式保持，无真实服务调用或凭据读取。
