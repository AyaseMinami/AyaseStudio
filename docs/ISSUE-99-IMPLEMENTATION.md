本地已补齐助手／聊天列表拖动排序，连同昨晚供应商／连接树切片覆盖 #99 的功能范围。助手与聊天均有左侧把手、名称长按、来源变淡、目标插入线、边缘自动滚动和菜单上下移。聊天限定同助手，不改变归属；拖动不打开或选择行，不触发编辑／删除。生成中的聊天仍可排序，工作区正在执行操作时禁用排序；既有删除与设置生成保护保持。

未手动排序的旧聊天仍按最近更新时间排列；首次实际换序后只为该助手内聊天保存连续 `sortOrder`。消息活动与标题更新不覆盖顺序，新建／分支置顶。原位与相邻同位置不冻结旧最近活动顺序。助手使用既有排名，供应商／连接顺序仍由共享连接设置管理，各列表独立。备份导出与校验增加可选有限数字聊天排名；旧备份没有该字段时仍有效，复制／替换恢复保留它，无新数据库表或索引。
