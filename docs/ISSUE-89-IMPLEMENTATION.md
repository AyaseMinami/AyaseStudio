# #89 绘图成果库、预览与常用操作

2026-10-01 拉取 [#89](https://github.com/AyaseMinami/AyaseStudio/issues/89) 正文、讨论和 #88／#90 后确认需求足够实施，无新增产品决定需要用户拍板。#88 已关闭。本记录不表示远端验收通过或 Issue 关闭。

## 实施合同

成果独立持久化：删任务保留成果，删成果保留成功历史。完成任务的出处不永久占有输出；草稿、所有任务／成果的输入、其他成果的输出及准备提交／活动输入继续保护资源。保存中／等待恢复的任务禁止删除已登记成果，避免重新登记。删除与引用编辑串行；DB 失败保留记录。清理前重读并校验持久拥有者及删除候选，损坏出处、未知状态／协议／描述或未确定草稿保存都阻止清理。整个输出组仍有引用就保留；不扫描全盘孤儿。两个完成态清理入口均验证 manifest／pending 身份和摘要，损坏、冲突保留文件。源文件和导出副本不在清理范围；清理失败与记录删除分别报告。

原生派生最长边 ≤256px PNG 缩略图，小图不放大、不写持久缓存；生成历史及成果网格按可见性读取。预览才读原图，离开生成视图／绘图页释放 URL，缩略图离屏释放；迟到响应不创建 URL。只验证所选图片的读取路径，缺失同组文件不阻碍有效图片预览；恢复和清理仍完整校验。原图／缩略图故障分别报告。

大图默认完整适应，滚轮或 +／− 缩放，拖动／方向键平移，0／按钮重置；边界按实际等比图像计算。成果切换复位，最新成功图自动选择，失败／取消保留旧图。参考图一键清空只改草稿列表。成果信息含提示词、实际模型 ID、协议、参数、时间和尺寸；复制不载入／生成。完整复用恢复对应协议及有序参考图，逐项报告缺失输入。目标失效保留文本与参数，持久 `reusedProtocol` 保留原协议控件直至明确重选；不自动换协议或发请求。异步保存失败只回滚仍属于本操作的草稿，保护期间的新编辑。#90 的任务复用和预设 CRUD 留在 #90。

普通 PNG 重新编码且无隐藏元数据。显式参数 PNG 写 UTF-8 `parameters` iTXt JSON：允许 `prompt`、实际 `model`、`protocol`、`api_type`（gemini/gpt），以及该协议显式发送的 `aspect_ratio`／`resolution` 或 `size`／`quality`；自动值省略。前端专用映射及原生 `deny_unknown_fields`／协议互斥排除 Key、私有地址、连接名称／ID、路径、参考字节及未知扩展。明示含提示词、不含参考原件、不保证确定复现，不生成 JSON 副文件。字段及读取核对固定 GNBP [GenConfig](https://github.com/AyaseMinami/gnbp-image-generator/blob/0c07f22a3f7c2762cd0584ff702ceae7b9e07e09/config/config_mgr.py) 和 [read_metadata](https://github.com/AyaseMinami/gnbp-image-generator/blob/0c07f22a3f7c2762cd0584ff702ceae7b9e07e09/core/utils.py)，未在应用嵌入 Python。旧 PNG 导入留在 #92。

单项／多选顺序调用保存对话框，取消停止后续项，单项失败继续其他项，汇总成功数及失败序号。删除使用应用内确认框，支持取消／Escape、焦点约束与恢复，确认时重新检查记录。
