## 1.9.13：从设置保存到 ZIP

供应商设置将格式化后的输入作为 `apiKey` 交给 `updateProvider`；LLM reducer 直接合并载荷到供应商对象。Redux Persist 使用浏览器 storage，排除列表没有 `llm`，未设置凭据加密 transform。普通备份复制整个 `Local Storage`；`skipBackupFile` 分支只影响 `Data`，不影响该配置来源。由此可以沿实际写入与复制链路确认凭据包含，依据不限于类型声明。[设置写入](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/pages/settings/ProviderSettings/ProviderSetting.tsx#L151-L160)、[reducer](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/store/llm.ts#L151-L163)、[持久化配置](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/store/index.ts#L85-L94)、[存储复制与精简分支](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L180-L228)。

手机文件入口调用 `getBackupData()`，其 JSON 直接包含 `localStorage`，未删供应商或密钥；主进程将该字符串直接写成 `data.json`。普通和旧 JSON 路径分别创建标准 ZIP，参数只有压缩级别及 ZIP64，没有密码或加密步骤。[手机调用](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/services/BackupService.ts#L75-L85)、[JSON 载荷](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/services/BackupService.ts#L886-L893)、[写入 JSON](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L277-L296)、[普通 ZIP](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L232-L251)、[旧 ZIP](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L329-L336)。

恢复也保留配置：普通备份将 `Local Storage` 暂存到恢复目录，启动时替换原目录；格式 5 恢复直接写回 `persist:cherry-studio`，没有排除 `llm` 或要求重新填写 API Key 的分支。因此源码支持恢复已备份凭据；本次未做真实恢复验收。[目录恢复](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L600-L613)、[启动替换](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/main/services/BackupManager.ts#L100-L119)、[JSON 恢复](https://github.com/CherryHQ/cherry-studio/blob/da22fb797343fd3760e5dd2d467eda9bf0017632/src/renderer/src/services/BackupService.ts#L915-L923)。

## 2.1.3：精简也复制含密钥的 SQLite

`normalizeApiKeyEntry` 只 trim 输入并返回 `key`；`replaceApiKeys` 将结果原值写入 `user_provider.apiKeys`。该列是 JSON 模式的 TEXT，而数据库通过 `better-sqlite3` 直接打开文件路径，初始化 PRAGMA 为 WAL、同步、外键和等待时间，没有 SQLCipher 或 key 设置。普通备份先 checkpoint，再复制数据库；精简筛选仍明确保留同一个数据库文件，复制结果的 SHA 指纹必须等于原文件。这个完整链路证实导出没有逐项移除或加密 API Key。[保留输入值](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/data/services/ProviderService.ts#L181-L191)、[数据库写入](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/data/services/ProviderService.ts#L814-L837)、[字段存储](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/data/db/schemas/userProvider.ts#L61-L65)、[数据库打开](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/data/db/DbService.ts#L46-L54)、[PRAGMA](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/data/db/DbService.ts#L153-L162)、[复制和指纹校验](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/services/LegacyBackupManager.ts#L364-L437)。

归档使用标准 `ZipArchive`，只有压缩／ZIP64 参数，把整个工作目录加入 ZIP；备份弹窗及调用只有精简布尔值，没有备份密码。恢复从备份中的 SQLite 建立工作库并写入提升日志，包含供应商表，未见清除密钥步骤。[ZIP 创建](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/services/LegacyBackupManager.ts#L453-L497)、[备份弹窗调用](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/renderer/pages/settings/DataSettings/BackupPopup.tsx#L35-L61)、[恢复工作库](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/services/LegacyBackupManager.ts#L972-L1019)、[数据库提升日志](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/main/services/LegacyBackupManager.ts#L1117-L1134)。手机文件函数的注释说明界面停用，载荷仅有 `localStorage`，不能据此声称 v2 当前配置密钥也由手机导出携带。[停用说明与载荷](https://github.com/CherryHQ/cherry-studio/blob/3b397393b129558dcfadfaf4141e2a2395ac5eeb/src/renderer/services/BackupService.ts#L311-L320)。

本次固定的 `main` 仍保留相同的 API Key 原值写入和完整／精简 SQLite 复制、无密码归档路径；这只描述此 SHA，不能保证未来分支不变。[当前写入](https://github.com/CherryHQ/cherry-studio/blob/0cd237652cd09fa49afa929178b5b61f946c9ea8/src/main/data/services/ProviderService.ts#L804-L827)、[当前备份](https://github.com/CherryHQ/cherry-studio/blob/0cd237652cd09fa49afa929178b5b61f946c9ea8/src/main/services/LegacyBackupManager.ts#L364-L497)。
