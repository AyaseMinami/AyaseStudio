# Ayase Studio 界面设计指示

## 最新一轮问答与快捷键（#17 / #50）

仅最新一轮有多个候选时，在助手消息操作栏“分支”后显示 `‹ 2/3 ›`，不在用户消息重复显示。箭头同时切换提问与回答，提示为“上一版问答 / 下一版问答”；编号说明当前问答版本。生成、保存操作和消息编辑期间禁用切换，切换后恢复箭头焦点。继续下一轮仅保留选中问答，其他候选永久丢弃。

新消息 Enter / Ctrl+Enter 发送，Shift+Enter 换行；编辑消息 Enter 仅保存，Shift+Enter 换行，Esc 取消；编辑用户消息 Ctrl+Enter 保存并发送。输入法组合输入、重复按键及其他修饰键不触发提交。编辑发送与重新生成均免确认，删除仍确认。输入框占位及编辑提示显示快捷键；旧轮编辑发送提示截断后续历史。

记录日期：2026-09-27。用于后续界面实现与样式调整，首版整理自本次供应商连接列表、详情页和下拉框的迭代。

本文记录可复用的设计约定、当前实现位置及确认状态。具体功能范围仍以 Issue 和用户当前指示为准；模块边界见 [ARCHITECTURE.md](ARCHITECTURE.md)，验证流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。当前数值是实现参考，可以根据实际窗口和用户反馈调整，不作为全应用必须套用的固定模板。

## 透明度设置（Issue #59）

2026-09-28 四项透明度及聊天背景的遮罩强度、模糊程度均在滑块右侧提供恢复默认图标，沿用色盘恢复按钮样式。统一透明度恢复侧栏 0%、输入栏 0%、消息气泡 6%（统一参考值 0%），不会强制三者同值；三个单项只恢复自身。遮罩恢复 65%，模糊恢复 0px；无背景或背景处理中随滑块禁用。恢复不修改图片、取景、适配方式或其他配色。

用户确认采用统一透明度、侧边栏、输入栏、聊天气泡四个滑块，范围均为 0–100%（0% 不透明）。最后一次调整生效：统一滑块一次覆盖三个区域，独立滑块只修改对应区域。三项不同时，统一控件显示橙色叹号、“已分别调整”和“各项不同”，滑块位置保留最近的统一值；悬停和键盘聚焦可读到覆盖说明。三项手动调成一致时，提示消失且统一滑块同步为共同值。

侧边栏指聊天中的助手栏与对话栏，两栏共用一个值；输入栏包含输入底板与工具区；聊天气泡同时包含用户和助手，助手独立颜色设置仍保留。仅底板 alpha 改变，文字、图标和交互状态不随之变透明。高透明度配复杂背景时需配合背景遮罩，不承诺任意背景下的对比度。

预览使用固定 1920×1080 的内部画布，按容器宽度整体缩放为 16:9，不再随当前窗口改变内部排版。包含主导航、40px 顶栏、192px/240px 两级侧栏、双方消息和输入区；728px 聊天内容列沿用真实窄内容模式的位置。预览与实际聊天共用透明度变量，背景取景固定按 16:9 计算；实际聊天背景继续适配真实窗口。偏好即时生效且本机持久化。此为当前会话确认方案，远端 Issue 未修改；验证结果见开发指南。

## 消息内图片预览（Issue #62）

粘贴图片的空名称或 `image.png` 等通用名称改为 `粘贴图片-MMDD-HHmmss.ext`（本机时间）；同秒多张或连续粘贴追加 `-2`、`-3`，并避开当前草稿已有名称。扩展名按剪贴板 MIME 选择 PNG/JPEG/WebP，保留图片字节、MIME 与修改时间。明确文件名、文件选择和拖入保持原名；不追溯修改历史附件。

后续按用户反馈补充输入栏交互：待发送图片保持紧凑文件标签，点击图标/文件名可打开大图预览，右侧 × 为独立移除按钮；非图片标签保持原行为。支持 Escape 关闭并返回标签焦点，关闭不改输入文字和附件。仅显式打开时读取图片，关闭后释放预览数据，不发送、不保存私有副本。

2026-09-27 用户确认图片应缩放到适合阅读的尺寸，不要求统一缩成小图标。消息中的单图预览区域最大 560×420px；多图按发送顺序排列为两列，每格最大 280×280px，窄内容区域改为单列。图片等比完整显示、不裁切、不强行放大小图，区域受消息可用宽度约束。固定预览占位避免异步加载改变阅读位置；长截图点击后查看更大尺寸。

用户和助手消息共用展示规则；非图片附件继续显示文件按钮，输入框中的待发送附件保持紧凑标签。点击图片打开现有弹窗，同一消息的图片可前后切换，支持左右方向键、Escape 关闭、焦点限制和返回入口。加载及错误状态保留稳定占位。缩放只改变显示，不修改原始附件、发送数据或协议。此为本轮实施约定，远端 Issue 未修改；主观视觉效果仍待用户确认。

## 紧凑列表

适用于供应商下的连接等同类配置条目：字段能横向比较，操作集中在右侧，减少逐条卡片和重复装饰。

- 表头用加粗字段名，正文保持较轻的字重。供应商连接列表使用“连接名称 / 协议类型 / Base URL / 操作”。
- 名称、协议、地址分列对齐，表头与正文共用列宽规则；不要将名称、协议和地址挤在一小块区域，其余位置大幅留空。
- 条目之间用细分隔线，保留悬停和键盘焦点反馈。无需给每条数据额外加完整圆角卡片。
- 右侧管理和删除图标在各行保持相同位置与尺寸，不随名称或地址长度漂移。
- 长名称和地址可省略显示，但必须有查看完整值的入口。当前采用 `title` 悬停提示，进入详情也能查看完整地址；提示不代替按钮的可访问名称。
- 窄区域优先调整列布局：当前名称和协议在第一行，地址独占下一行；表头应同步调整。不要让长 URL 撑宽整个页面。
- 没有条目时给出明确空状态，并保留“添加连接”入口。

### 图标与操作语义

- 本列表的铅笔表示进入对应连接的管理详情，沿用原有跳转；整条主内容区域也可进入详情。这里不新增行内编辑模式。
- 删除为独立按钮，不应误触跳转。确认信息包含连接名称、协议、地址及连带删除的模型数量，便于区分同名连接。
- 浏览连接只改变当前详情，不改变助手默认模型或当前会话模型。
- 沿用现有生成期间禁用删除、未保存编辑确认和模型引用处理。样式调整不另加业务规则。
- 从供应商概览删除连接后，当前实现将焦点移回“添加连接”。

上述铅笔与删除约定适用于连接管理，不要求其他场景放弃自己的编辑或确认语义。

## 详情页与返回导航

- 返回入口放在详情标题上方，使用左箭头和明确文本“返回供应商连接列表”，回到该连接所属供应商。
- 返回箭头的左边缘、供应商名、连接名和下方表单左边缘对齐。不要给返回按钮额外的水平内边距造成视觉缩进。
- 供应商名作为次级上下文，连接名作为主标题；标题与分隔线之间保留留白。
- 显式控制标题区的 margin、gap 和行高，避免浏览器默认段落间距与组件间距叠加。
- 返回复用现有供应商选择流程，包括未保存模型编辑的放弃确认；不另建一套导航状态。

## 原生下拉框

所有可见原生单选下拉框复用全局箭头与文字留白规则，保留原生选择、键盘操作及禁用行为。

- 箭头统一向内收，与控件右边缘保持约 12px 间距；文字预留箭头区域，长选项不能挤到图标下面。
- 浅色、深色主题使用对应箭头颜色。新页面应沿用全局规则，不再单独包一层箭头或重复覆盖。
- 固定控件高度时，同时核对行高、上下内边距和边框所占空间。背景适配框曾在 36px 高度中沿用上下各约 10px 的通用内边距，导致文字裁切；现已去掉该控件上下内边距。
- 不将原生下拉框规则套到折叠区箭头、菜单触发器或自定义模型选择弹窗。
- 助手图标选择器 `#assistant-icon` 是透明原生控件覆盖可见图标，保留现有布局，不添加可见箭头。

2026-09-27 源码共发现 10 处 `<select>` 声明，其中 9 处使用可见下拉框规则：连接协议选择（新增和详情）、复制连接配置、背景适配、助手模型、对话模型、生成参数自动/自定义、思考强度、思考力度。参数控件可按字段重复渲染，声明数不代表实际页面控件数。
