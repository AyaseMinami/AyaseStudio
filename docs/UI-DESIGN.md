## 紧凑列表

适用于供应商下的连接等同类配置条目：字段能横向比较，操作集中在右侧，减少逐条卡片和重复装饰。

- 表头用加粗字段名，正文保持较轻的字重。供应商连接列表使用“连接名称 / 协议类型 / Base URL / 操作”。
- 名称、协议、地址分列对齐，表头与正文共用列宽规则；不要将名称、协议和地址挤在一小块区域，其余位置大幅留空。
- 条目之间用细分隔线，保留悬停和键盘焦点反馈。无需给每条数据额外加完整圆角卡片。
- 右侧管理和删除图标在各行保持相同位置与尺寸，不随名称或地址长度漂移。
- 长名称和地址可省略显示，但必须有查看完整值的入口。当前采用 `title` 悬停提示，进入详情也能查看完整地址；提示不代替按钮的可访问名称。
- 窄区域优先调整列布局：当前名称和协议在第一行，地址独占下一行；表头应同步调整。不要让长 URL 撑宽整个页面。
- 没有条目时给出明确空状态，并保留“添加连接”入口。

### 图标与操作语义

- 本列表的铅笔表示进入对应连接的管理详情，沿用原有跳转；整条主内容区域也可进入详情。这里不新增行内编辑模式。
- 删除为独立按钮，不应误触跳转。确认信息包含连接名称、协议、地址及连带删除的模型数量，便于区分同名连接。
- 浏览连接只改变当前详情，不改变助手默认模型或当前会话模型。
- 沿用现有生成期间禁用删除、未保存编辑确认和模型引用处理。样式调整不另加业务规则。
- 从供应商概览删除连接后，当前实现将焦点移回“添加连接”。

上述铅笔与删除约定适用于连接管理，不要求其他场景放弃自己的编辑或确认语义。

## 详情页与返回导航

- 返回入口放在详情标题上方，使用左箭头和明确文本“返回供应商连接列表”，回到该连接所属供应商。
- 返回箭头的左边缘、供应商名、连接名和下方表单左边缘对齐。不要给返回按钮额外的水平内边距造成视觉缩进。
- 供应商名作为次级上下文，连接名作为主标题；标题与分隔线之间保留留白。
- 显式控制标题区的 margin、gap 和行高，避免浏览器默认段落间距与组件间距叠加。
- 返回复用现有供应商选择流程，包括未保存模型编辑的放弃确认；不另建一套导航状态。

## 原生下拉框

所有可见原生单选下拉框复用全局箭头与文字留白规则，保留原生选择、键盘操作及禁用行为。

- 箭头统一向内收，与控件右边缘保持约 12px 间距；文字预留箭头区域，长选项不能挤到图标下面。
- 浅色、深色主题使用对应箭头颜色。新页面应沿用全局规则，不再单独包一层箭头或重复覆盖。
- 固定控件高度时，同时核对行高、上下内边距和边框所占空间。背景适配框曾在 36px 高度中沿用上下各约 10px 的通用内边距，导致文字裁切；现已去掉该控件上下内边距。
- 不将原生下拉框规则套到折叠区箭头、菜单触发器或自定义模型选择弹窗。
- 助手图标选择器 `#assistant-icon` 是透明原生控件覆盖可见图标，保留现有布局，不添加可见箭头。

2026-09-27 源码共发现 10 处 `<select>` 声明，其中 9 处使用可见下拉框规则：连接协议选择（新增和详情）、复制连接配置、背景适配、助手模型、对话模型、生成参数自动/自定义、思考强度、思考力度。参数控件可按字段重复渲染，声明数不代表实际页面控件数。

## 实现入口与当前参考值

优先使用现有主题与字号变量，沿用项目的系统字体栈。新样式使用 `--color-text`、`--color-muted`、`--color-border`、`--color-hover`、`--color-focus` 等语义变量；字号优先使用 `--font-caption`、`--font-small`、`--font-ui` 和 `--font-section`。本轮局部实现仍有等值的 rem 写法，不代表已经完成全局样式归一。

| 位置 | 职责与定位标识 |
| --- | --- |
| [App.css](../src/App.css) | 全局字体与主题变量；`--select-chevron` 和 `:root select:not([id="assistant-icon"])` 管理下拉箭头。 |
| [ConnectionSettings.tsx](../src/ui/settings/ConnectionSettings.tsx) | 连接列表表头、铅笔入口、删除和从详情返回列表的交互。 |
| [ConnectionSettings.css](../src/ui/settings/ConnectionSettings.css) | `.provider-connection-*` 列表布局；`.connection-detail-heading` 与 `.connection-back-button` 标题和返回入口。 |
| [AppearanceSettings.css](../src/ui/settings/AppearanceSettings.css) | `.appearance-row .field` 控件高度、行高和局部内边距；不再独立绘制下拉箭头。 |

以下为当前工作树的样板值，便于追溯和继续调整：

| 部位 | 当前参考值 |
| --- | --- |
| 连接列表 | 最大宽度 64rem；主入口最小高度 3rem；名称/协议/地址使用 `minmax(0, 1fr) 9rem minmax(0, 2fr)`。 |
| 列表响应式 | 容器不超过 38rem 时地址独占第二行；不是按整个窗口宽度判断。 |
| 列表文字 | 表头 13px / 700；名称 14px / 500；协议与地址 13px。 |
| 详情标题区 | 间距 0.25rem；分隔线上方留白 0.875rem；返回入口无水平内边距。 |
| 下拉箭头 | 图标 1rem；距右侧 0.75rem；文字右内边距 2.25rem。 |
| 背景适配控件 | 高度 2.25rem，行高 1.25rem，上下内边距为 0；右侧文字留白由全局下拉规则覆盖。 |

上表 px 换算以当前根字号 16px 为基础；局部尺寸不是新的全局 token。

## 后续使用与维护

涉及 UI 时先读本文，再检查对应组件及 CSS。同类问题在多个页面出现时，先查全局与局部样式的覆盖关系，优先在共用位置修正；避免每个页面重复加包装或相互覆盖的样式。

视觉核对聚焦于实际改动：字段和操作列对齐、长内容、窄区域重排、中文是否裁切、箭头留白，以及浅深主题和焦点状态。代码检查不能替代实际显示确认；按用户当前指示和开发指南安排验证，不把本轮未执行的检查写成已通过。

新的用户反馈改变约定时，同步更新本文的相关规则和确认状态。仅改变局部数值时更新参考值；不要据此扩展成无关页面的重设计，也不要在文档中保存真实凭据或含密钥的截图。
