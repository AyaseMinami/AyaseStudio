# Ayase Studio 界面设计指示

## Gemini 高级参数功能入口（#101）

用户要求功能优先、视觉设计后置。生成页沿用现有控件，Gemini 参数区新增默认收起的“Gemini 高级参数”：温度可选 0–2／恢复模型默认、四类统一安全阈值／服务默认、文字＋图片或仅图片。高级控件只随 Gemini 目标显示，切换模型保留两种协议的独立草稿；不新增页面临时协议切换。非法温度显示错误且不保存／提交，载入有效参数或恢复默认解除错误；详细映射与证据见 [#101 记录](ISSUE-101-IMPLEMENTATION.md)。

## 绘图提示词预设与历史复用 #90（本地实现）

提示词下方提供纯文本预设选择及新建／更新／另存／编辑／删除。选择立即替换提示词，模型、两套协议参数和参考图保持；草稿编辑不自动写回预设。更新取当前草稿文字，编辑取已保存文字；弹窗只编辑名称和内容，明确保存才提交，取消／Escape／关闭丢弃临时编辑，失败保留表单。同名预设按稳定 ID 区分。弹窗通过 portal 居中呈现，约束焦点并在关闭后回焦；背景 inert，窄屏可滚动，生成过程中仍可管理预设。

任务行与成果详情均提供复制提示词和复用参数。复制不载入；复用直接回填对应字段并返回生成页，不弹覆盖确认、不自动生成、不修改历史。失效模型保留对应协议控件并要求重选，缺失参考图逐项提示。沿用现有主题、圆角和窄屏布局。详见 [实施与验收](ISSUE-90-IMPLEMENTATION.md)。

## 绘图成果库 #89（本地实现）

成果库有按需缩略图、单项／多选普通或显式带参数 PNG、应用内删除确认。历史切换同一大图，默认完整适应，滚轮／键盘缩放、拖动／方向键平移、0／按钮重置；切换复位。离开预览释放原图、缩略图离屏释放，故障区分。详情含提示词、实际模型、协议、参数、时间、尺寸及复制／完整复用／作为参考入口；失效目标保留原协议控件并要求重选。参考图清空保留其他字段。沿用主题、圆角和窄屏布局。参数导出明示含提示词、不含参考原件、不保证确定复现。见 [实施及验收](ISSUE-89-IMPLEMENTATION.md)，下方旧切片状态为历史记录。

## 绘图任务管理 #88（本地实现）

任务页增加单批取消、终态重新生成、单条删除及清空完成／失败历史。未知结果重新生成提示重复生成／计费；删除确认汇总未知结果风险和保存失败的逐图恢复情况，不删除独立成果。采用应用内可滚动确认框，初始聚焦取消，支持 Escape、焦点约束和关闭后焦点恢复；所选任务信息变化时禁止使用旧确认。诊断详情显示中文类别和 HTTP 状态，不展示原始正文／Key／路径。保存阶段不能取消，活动任务不能删除。详见 [实施与验证边界](ISSUE-88-IMPLEMENTATION.md)。

## 批量队列 #87（本地实现）

数量开放为 1–99，并发 1–4，完成提示音可关闭，三者记住设置。运行中可继续入队；任务区显示阶段计数、执行耗时、暂停／继续与取消，明确取消不撤销远端计费。已知终态耗时停止增长。原有 4:6 双栏保持；详见 [实施与验收边界](ISSUE-87-IMPLEMENTATION.md)。下方核对记录中的队列部分由本节取代，其余保持后续范围。

## 助手／聊天列表排序（#99，2026-10-01 续作）

用户已授权补齐 #99。助手及聊天行最左侧显示拖动把手，名称按钮长按 400ms 也能拖动；把手移动 6px 激活，提前移动取消名称长按。拖动项变淡、目标上下边缘显示插入线，列表边缘自动滚动。助手全局排序，聊天只在当前助手内排序；跨列表放置无效，不改变归属。松手才保存，原位／相邻同位置／列表外不改顺序；Escape 只取消本次手势，不收起导航，失焦／隐藏／resize／指针取消／来源消失／打开弹窗／工作区忙碌亦取消。拖动释放不触发选择、展开、编辑或删除。

两类菜单均提供上移／下移及首尾禁用，通过右键或 Shift+F10／菜单键可访问；保存成功后礼貌播报，失败沿用工作区错误提示。排序保持当前助手／聊天、模型、配置和草稿，也可在后台生成时使用。未手动排序的聊天仍按最近更新时间排列；首次实际手动换序后固定该助手内顺序，消息更新与自动标题不改变它，新建／分支聊天放顶部。旧导入记录未带顺序时按最近更新时间置于手动排序记录前，之后的手动排序会统一保存。默认助手也可排序，删除限制保持。实现为 `ConversationNavigation.tsx`、`useNavigationListDrag.ts`、`App.css` 与工作区 repository 命令。下方供应商／连接步骤已完成，本段取代其中“助手／聊天待讨论”的历史状态；实施后用户已授权 Git 交付和关闭 #99，交付记录见 Issue 评论。

## 供应商与连接拖动（#99 第二步）

2026-10-01 用户确认先调整连接配置树：供应商和连接行最左侧均显示拖动把手，供应商把手位于展开按钮之前。把手按住移动即可拖动；名称区域长按 400ms 后也可拖动，提前移动取消长按，普通单击沿用查看操作。展开按钮、添加按钮和管理菜单不作为拖动起点。供应商按整组排序，连接只在所属供应商内排序；跨供应商放置无效，不改变归属。右侧连接概览沿用同一排序结果，其管理菜单可上移／下移。

拖动项变淡、目标前后边缘显示插入线，列表边缘自动滚动。松手才保存顺序；原位、列表外、Escape、失焦、指针取消及生成开始均不提交排序，拖动或已激活长按不会变成查看点击。拖动保留当前连接、默认模型与未保存模型编辑。两种对象菜单均提供上移／下移，首尾及生成中禁用对应操作；状态通过礼貌播报告知辅助技术。实现位置为 `ConnectionSettings.tsx/.css`、`useConnectionTreeDrag.ts` 与连接配置命令。助手／聊天拖动仍待后续讨论。此步骤在 #99 原范围上补充连接排序，远端 Issue 尚未修改。

## 背景模糊修复（#96）

调整背景模糊只改变清晰度，不改变取景中心、用户缩放或填充／适应的构图。旧实现将模糊值映射为 `1 + blur / 100` 的额外缩放，32px 时放大到 132%；现已移除此绑定。

实际背景、外观预览、背景库预览与取景效果预览共用 `BackgroundImage` 的图片内部高斯模糊。仅在原图外延展最外侧像素供模糊采样，随后裁回原图范围，避免强模糊边缘透出画布色；适应模式及超出图片的取景保留原有空白。预览仍按固定 1920×1080 画布整体缩放。透明度和遮罩规则不变，面板局部毛玻璃另见 [#98](https://github.com/AyaseMinami/AyaseStudio/issues/98)，不包含在本次修复中。

## 应用内右键菜单（#74，2026-09-30 修订）

按用户本次确认，默认屏蔽应用页面的 WebView 右键菜单；输入框、消息编辑框及可编辑文本保留原生编辑菜单。Gemini 搜索建议的独立 iframe 同样绑定此策略，维持其原有无脚本沙箱。文字选择和复制快捷键不拦截。仅助手悬浮列表、对话悬浮列表、供应商条目和连接渠道条目提供自定义菜单；聊天正文与列表空白不新增菜单，消息继续使用原操作按钮。此范围替代 #74 的消息右键方向，并增加供应商与连接渠道；用户已实测确认通过并授权将远端 Issue 同步为此范围。

助手菜单为编辑、上移、下移、删除；对话菜单为编辑对话、删除；供应商菜单为重命名、上移、下移、删除；连接菜单为编辑、重命名、上移、下移、删除，覆盖左侧树与供应商连接概览（排序为 #99 第二步补充）。右键及菜单键／Shift+F10 只打开目标菜单，不自动切换选择。现有管理按钮和右键共用操作；对话删除转到目标行的取消／确认删除并聚焦确认按钮，消息与助手及供应商／连接的既有删除确认保留。

统一 `ActionMenu` 使用主题面板底色、8px 圆角、细边框、轻阴影和危险色，底板不随聊天透明度滑块改变。菜单经 portal 挂到 body，按实际尺寸限制在视口 8px 留白内，低高度时内部滚动。仅保留一个对象操作菜单；外部点击、Escape、菜单 Tab、滚动、窗口失焦／resize、切换视图或目标隐藏／消失时关闭。Escape 不继续收起侧栏；外部点击不抢回焦点。方向键与 Home/End 跳过禁用项，Enter 执行；重命名表单的 Tab 正常访问输入与取消／完成，离开表单或取消丢弃草稿，显式完成才保存。

消息生成期间不允许删除目标对话或其所属助手，默认助手不可删除；助手／对话编辑仍沿用下一次请求生效的规则。供应商／连接修改继续按全局生成保护禁用。实现位置为 `src/ui/ActionMenu.tsx/.css`、`ConversationNavigation.tsx`、`ConnectionSettings.tsx`；验证记录见开发指南。

## 网络搜索（#80）

连接配置之后新增“网络搜索”分类。用户后续明确拆为 Exa API 与 Exa MCP 两张配置卡，分别保存地址、遮罩 Key 和 1–10 结果数量。API 必填 Key；MCP Key 选填且说明匿名限流。各卡有恢复官方地址、单独清空 Key、显式保存和固定公开问题测试/停止；保存一张卡保留另一张已保存配置与未保存草稿。失败保留草稿；损坏配置须显式载入默认草稿，保存才覆盖原记录。测试草稿不代表保存，打开与保存不联网。说明查询发送目的地和本机明文保存。

地球入口保持原位置，提供关闭／模型原生／Exa API／Exa MCP 四项，显示当前模式，支持方向键、Home/End、Escape/Tab 和焦点恢复。助手/对话参数使用相同语义，旧启用会话保留模型原生，旧 Exa MCP 保持 MCP。检索显示实际接入名称，成功显示“已检索 · N 个来源”；展开来源可看摘录与查询。检索成功和回答失败分别显示；回答结束但无合法引用时提示“已检索资料，正文未提供有效引用”，生成中不提前提示。回答候选各自恢复来源，角标复用受限外链。

备份预览列出搜索配置与包含搜索 Key 的凭据计数；搜索专用 Key 同样受替换确认保护。实现位置：`NetworkSearchSettings`、`WebSearchModeControl`、`SearchResults`、`BackupWorkspace`。浏览器合成验收和真实/native 验收分别记录，见 [实施记录](ISSUE-80-IMPLEMENTATION.md)。

## Ayase 备份与恢复（#79）

## 紧凑列表

适用于供应商下的连接等同类配置条目：字段能横向比较，操作集中在右侧，减少逐条卡片和重复装饰。

- 表头用加粗字段名，正文保持较轻的字重。供应商连接列表使用“连接名称 / 协议类型 / Base URL / 操作”。
- 名称、协议、地址分列对齐，表头与正文共用列宽规则；不要将名称、协议和地址挤在一小块区域，其余位置大幅留空。
- 条目之间用细分隔线，保留悬停和键盘焦点反馈。无需给每条数据额外加完整圆角卡片。
- 右侧管理和删除图标在各行保持相同位置与尺寸，不随名称或地址长度漂移。
- 长名称和地址可省略显示，但必须有查看完整值的入口。当前采用 `title` 悬停提示，进入详情也能查看完整地址；提示不代替按钮的可访问名称。
- 窄区域优先调整列布局：当前名称和协议在第一行，地址独占下一行；表头应同步调整。不要让长 URL 撑宽整个页面。
- 没有条目时给出明确空状态，并保留“添加连接”入口。

### 图标与操作语义

- 本列表的铅笔表示进入对应连接的管理详情，沿用原有跳转；整条主内容区域也可进入详情。这里不新增行内编辑模式。
- 删除为独立按钮，不应误触跳转。确认信息包含连接名称、协议、地址及连带删除的模型数量，便于区分同名连接。
- 浏览连接只改变当前详情，不改变助手默认模型或当前会话模型。
- 沿用现有生成期间禁用删除、未保存编辑确认和模型引用处理。样式调整不另加业务规则。
- 从供应商概览删除连接后，当前实现将焦点移回“添加连接”。

上述铅笔与删除约定适用于连接管理，不要求其他场景放弃自己的编辑或确认语义。
