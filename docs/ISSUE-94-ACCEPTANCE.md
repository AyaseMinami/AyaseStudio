## 测量环境与方法

- 机器记录：Windows 10 Pro，build 19045；Intel Core i9-14900KF，24 核／32 线程；RAM `68,497,981,440` 字节。WebView2／浏览器 UA 的 Chromium/Edge 为 154。原生 1040×760、DPR 1.25；浏览器 1280×900、DPR 约 1。
- 本轮性能运行使用 Vite 开发服务和 debug Tauri，不是 Release 构建。入口 [scripts/drawing94/acceptance.tsx](../scripts/drawing94/acceptance.tsx)，数据库为 `Drawing94-Synthetic-browser-<dataset>`／`Drawing94-Synthetic-native-<dataset>`，dataset 由本机隔离 URL 选择；按各冻结报告的 seedReport 记录实际起点。完整参考图／持续失败使用另建的合成数据库。不挂载普通 App，不读取正式用户配置、真实凭据或正式数据库。
- 合成 PNG：初始设计 1,000 成果，12 张 4096×4096、其余 512×512。浏览器文件保存／读取／缩略图／导出为内存假边界；原生使用真实 `runtimeDrawingFiles` 和隔离应用私有目录。两者均运行真实绘图 controller、Dexie、DrawingWorkspace 和协议 adapter，fetch 返回合成响应。
- 每轮 99 项、并发 4、禁音；生成完成后保留页面 1 秒，再卸载绘图页面／释放合成缓存，等待 30 秒空闲。`performance.memory.usedJSHeapSize` 每 50 ms 采样，longtask observer 记录长任务。受主线程调度及 GC 影响，采样最大值不能称为真实瞬时峰值；JS 堆不包含完整图片解码／GPU／全部 WebView 内存。
- [sample-native.ps1](../scripts/drawing94/sample-native.ps1) 每约 1 秒采样本轮仓库进程及其 WebView2 子进程，记录 `PrivateMemorySize64`／`WorkingSet64` 求和。WS 共享页可能重复计数；采样只覆盖可观测时刻。最终压力报告时间窗的起点由结束时间和耗时推算，关联过程样本只作近似。

### 持续保存失败与释放

冻结证据：`.drawing94.local/memory-failure-final.json`，入口 [memory.tsx](../scripts/drawing94/memory.tsx)。浏览器真实 controller／Dexie／adapter，模拟文件与暂存完全不可写。12 个 2048×2048 噪声 PNG 响应，每个 14,431,260 字节（13.76 MiB），保留图片字节合计 173,175,120（165.15 MiB）。运行 3,576.3 ms、请求 12 次，12 项 save-failed、paused=false；页面明确提示“12 项任务的 12 张图片仅保存在内存”及继续增长／退出丢失风险。

JS 堆采样最大／保留时 409,706,524 字节（390.73 MiB）；本地重试 1 项并明确删除其余 11 项、空闲后为 74,684,147 字节（71.22 MiB）。请求次数仍 12、保留成果 1、内存图片 0、警告已清除。没有自动暂停或丢图；失败持续累积仍可增长，风险提示不是内存限制。该测量不证明无限失败时可持续运行，也没有故障注入用户实际磁盘。

### 显式预设／设置备份容量与三策略

冻结证据：`.drawing94.local/browser-backup-final.json`。在实际 1,495 成果／495 任务的隔离库上，五轮分别构造 10,000 个显式纯文本预设，经真实投影、codec 编码／解码核对数量。每包 6,411,612 字节（6.11 MiB），处理耗时 861.7／875.8／847.7／891.9／846.1 ms，中位数 861.7 ms；采样 JS 堆最大 485,674,891 字节（463.18 MiB）。这是页面及此前存活对象在采样点的堆值，不是精确增量峰值。

绘图文件 read／write／delete 守卫未触发；portable drawing 区域不包含图片引用／自动草稿／任务成果历史。实际 merge／copy／replace 三策略均保留全部 1,495 成果和 495 任务、原自动 prompt `#94 合成批量压力`，每策略新增供应商派发 0。8 MiB 文本／80 MiB 文档／128 MiB 文件预算仍按原合同处理；本轮全量回归包含超 8 MiB 明确拒绝，不截断输入或清空本机数据。本容量样例低于文本预算，不代表已处理任意容量。
