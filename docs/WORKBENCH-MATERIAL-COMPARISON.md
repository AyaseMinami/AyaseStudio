# 设置与绘图容器对照（2026-10-03）

## 范围与方法

用户要求设置与绘图按各自任务设计，保持同一产品风格，并使用上一轮 imagegen
生成的成年二次元人物背景调试。没有生成新背景、访问个人素材或请求供应商。
使用 [独立预览夹具](../scripts/workbench-material/README.md) 挂载真实工作区与控件；
绘图包含三条已完成的合成任务及独立本地绘制的 PNG，不是实际生成结果。

## 对照过程

| 轮次 | 对照 | 观察与选择 |
| --- | --- | --- |
| 1 | 原样、不透明底板、7% 与 15% 轻透；浅深主题 | 轻透让人物／建筑轮廓进入表单、提示词、任务及成果操作区。15% 更明显。保留不透明底板，背景在页面留白与导航中参与氛围。 |
| 2 | 不透明底色、柔和边缘、8px 间距 | 浅色微调为中性浅灰，深色稍提亮，主面板保持稳定；移除设置外部重复框、参考图区重复虚线，分组仍可辨认。 |
| 3 | 实际生产 CSS；1600×1000、1280×900、640×820；无背景与遮罩 45%／65% | 检查真实主题、面板颜色、画布底色、布局与滚动；结果记录在开发指南。 |

用户已确认采用此版不透明工作台样式。7%／15% 仅存在于隔离夹具的对照选项。
实际面板采用主题面板色 98% + 正文色 2%，描边为正文色 8%，圆角 12px；弱阴影
为 `0 1px 2px`、阴影色 3.5%。绘图画布及输入控件保留原不透明底色，未改变图片字节。
聊天 40%／50%／12%、背景遮罩和玻璃开关的已存值不变；未新增持久字段。
