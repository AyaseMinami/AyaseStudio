# 透明度与对话注意力对照（2026-10-03）

## 本轮目标与结论

用户明确聊天气泡是阅读核心，助手／对话导航应降低视觉重量。用内置 imagegen 生成原创二次元成年女性壁纸，画面包含人物、樱花、建筑、灯光和水面，同时覆盖明暗与细线区域。在真实聊天组件的隔离夹具中比较外框、导航和气泡背景，正文及控件透明度保持不变。

当前默认为外框 **40%**、侧栏 **50%**、气泡 **12%**，取代前一轮 75／20／6。建议调节起点为外框 35%–45%、侧栏 45%–55%、气泡 6%–12%；外框与侧栏可成组保持约 10 个百分点差距。这是本轮画面、主题、遮罩与布局下的视觉判断，不是任意壁纸的可读性保证，也不限制用户的 0–100% 设置。浅色下外框略白于导航，气泡保留较实的阅读底色；深色下按对应主题底色合成，不强求同样的亮度顺序。

## 对照过程

统一使用 1440×900、默认配色、侧栏玻璃关闭，默认全局遮罩 65%、输入玻璃开启。背景图片通过现有 `BackgroundImage` 渲染，未用 CSS 滤镜改变原图。遮罩 45% 只用于额外压力观察，默认遮罩仍为 65%。

| 轮次 | 候选与观察 |
| --- | --- |
| 1 | 浅色外框／侧栏 75／20、25／35、40／50，气泡 6%；40／50 降低全高侧栏白底的重量，同时保持整体外壳。 |
| 2 | 浅色 35／45、45／55、50／60、60／70，气泡 6%；70% 侧栏透出的灯光与建筑线条更明显，45%–55% 更适合作为默认调节区间。 |
| 3 | 固定 40／50，浅色气泡 6／12／20／30%；12% 轻微减轻实底感，30% 已能辨认文字后面的五官与灯光。 |
| 4 | 深色 75／20、35／45、40／50、60／70 及气泡 12／20／30%；40／50／12 保持清晰文本与导航区分。 |
| 5 | 浅深主题的长正文／代码块，气泡 12 与 30 对照；12% 保留稳定的阅读底色。 |
| 6 | 浅深主题 40／50／12，遮罩降为 45%；细节更明显，正文仍清晰。恢复 65% 遮罩后检查浅深纯色与 640×820 窄屏，无横向页面溢出。 |

窄屏复查发现导航浮层的 50% 底色会叠出下方聊天文字。未开启侧栏玻璃时，浮层显示底色不透明度下限提高为 94%，不写回保存值；桌面并排仍使用 50% 底色，玻璃开启沿用现有模糊材质。外观透明度帮助说明补充此规则。浏览器核对浅深主题、侧栏 0／100% 端点、玻璃开关及返回桌面后的 .5 背景 alpha。该规则以浮层实际状态判断，适用于所有导航未停靠的布局。

两种气泡仍共用既有透明度字段；没有增加玻璃、字段、迁移、资源引用或按壁纸自动修改参数的逻辑。新建、缺失字段与恢复默认读取同一个默认对象；旧显式 85／0／6、75／20／6 等保持。数据与备份规则见 [DATA-CONTRACTS.md](DATA-CONTRACTS.md)，实现及隔离运行见 [DEVELOPMENT.md](DEVELOPMENT.md) 和 [夹具说明](../scripts/chat108/README.md)。
