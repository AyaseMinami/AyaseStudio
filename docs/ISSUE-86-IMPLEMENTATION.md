# 多参考图输入 #86 实施记录

2026-10-01，按用户确认在 `dev` 本地实现。远端 Issue 的输入预算／预处理提案由本次确认取代，远端正文未修改；确认项见 [#83 规格](ISSUE-83-DRAWING-SPEC.md)。

## 实现范围

- 多选、拖入绘图区域、粘贴图片；编号、查看、上移／下移和移除。
- PNG/JPG/JPEG/WebP/BMP 沿用 GNBP 支持范围，无新增输入张数、容量或像素上限；本地不可读／损坏文件显示错误，服务兼容性由模型服务商校验。
- 相同字节／资源重复添加时提示并跳过。当前成果和成果库可追加为参考图，保留提示词、模型和参数，不自动发请求；生成后不清空参考图。
- 原图私有复制、参考图草稿及顺序持久化；请求冻结输入，生成时仍可编辑下一次草稿。旧草稿缺少引用字段时按空列表处理，不迁移数据库。

不包含蒙版／裁切编辑器、批次／队列、聊天联动、预设或完整资源 GC。

## 文件与任务归属

`drawing.rs` 识别实际 PNG/JPEG/WebP/BMP、读取尺寸及 SHA-256，将原字节原子保存到 `drawing/references/<UUID>.<ext>`；不缩放、不重新编码、不压缩、不抹掉透明度。成果追加直接引用已有不可变成果文件。原生读写及删除复用现有绘图互斥与受管路径／重解析点检查；删除命令只接受参考图目录的合法 UUID 文件，不删除成果或用户文件。

controller 串行化参考图编辑与草稿保存。活动任务在异步准备之前持有冻结引用；已登记的任务即使失败、取消或结果未知仍保留输入。移除草稿图仅释放未被草稿、活动任务、任务历史或成果参数持有的导入文件。添加／提交失败产生的无主临时副本可释放，草稿持久化状态未知时保留文件。关闭整理等待已接受的引用操作；没有启动扫描或新增资源回收体系。

## 请求映射

Gemini 在提示词之后按列表顺序发送原图 `inlineData`。OpenAI Images 有参考图时改用 `/images/edits` 与 multipart `image[]`，发送原字节和实际 MIME，文件名为请求内生成的编号；无参考图保持 `/images/generations` JSON。保留原参数及单张请求，自动参数省略；不做无声丢图、降级、重试或供应商探测。现有输出响应预算不用于限制输入。

官方要求和链接见 [协议合同](PROTOCOLS.md)。本次未发现官方要求缩放、JPEG 转换或透明度处理，因此未实现任何预处理。
