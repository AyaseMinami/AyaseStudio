日期：2026-10-02。范围：[Issue #110](https://github.com/AyaseMinami/AyaseStudio/issues/110)。本记录区分本地实现、确定性测试、浏览器交互、隔离原生测量与用户手动接受；不表示提交、推送或关闭 Issue。

最终用户验收（2026-10-02）：用户确认参考图优化效果、真实 GPT Image 生成／参考图编辑成功，缩略图复用修正后完成测试；补齐主窗口 destroy 权限后，用户再次确认正常关闭可用，并明确授权推送代码及关闭 #110。下文“未验收／未交付”描述为各阶段当时的边界；本次用户确认覆盖其实际使用路径，不扩大成所有供应商与中转服务的兼容证明。实际提交和关闭状态以远端 Issue 的交付评论为准。

## 决策与来源

核对 GNBP 桌面固定 revision `0c07f22a3f7c2762cd0584ff702ceae7b9e07e09` 的 `ui/main_window.py`（选图／预览与路径列表复制）、`core/api_client.py`、`core/gpt_client.py`、`core/utils.py`。借鉴先预览、执行时处理的时机。其运行时重新打开源路径、部分失效跳过和 Gemini 缩放／JPEG 85 压缩不作为 Ayase 合同；未复制源码或素材。

直接持有磁盘 `File` 或 `new Blob([file])` 不能充当已验证的独立原字节副本。选择阶段实际执行一次 `file.arrayBuffer()`，再由这些字节构造新 Blob。预览与提交均从该 Blob 读取，成功捕获之后的源文件修改、删除、移动不会改变输入；捕获失败则本次多文件选择整体不加入，之前选择保持。选图仍有一次原字节读取及浏览器预览解码成本，并保留会话内存；不承诺零拷贝、固定内存预算或磁盘读取瞬时完成。

## 状态与资源合同

- `DrawingState.references` 是独立会话选择，联合类型仅为字节 Blob 或已受管原图描述符。普通切页不销毁控制器；UI 为缩略图及弹窗创建／回收各自 Object URL。移除或换页释放 URL，提交快照需要的 Blob 继续保留至准备结束。
- 新选择、成果追加和历史复用不导入原图、不写参考图草稿，不读取成果完整原图。受管资源缩略图仍使用已有原生缩略图接口，点击才读大图。缺图在缩略图或明确提交校验时报告，不跳过后继续发送。
- 提交同步冻结参数、数量、有序选择与受管资源保护。逐张准备最终输入，SHA-256 按原字节去重、保留首次顺序；优先复用同批中的有效受管原图。新原图经二进制 IPC 全解码校验、摘要与原字节可靠保存。整批准备成功后，复用已有 `enqueue` 事务登记任务；每张唯一新原图每批只导入一次，供应商逐任务读取／编码仍在并发槽内。
- 提交成功后，只把仍在当前会话中的对应选择替换为已受管描述符并去重；用户在准备期间的移除、追加、排序及草稿修改保留。后续再次提交复用已导入文件。任务／成果成为独立持久所有者，清空会话不会删掉它们需要的原图。
- 新“取消准备”只取消当前提交，不取消先前正在执行或排队的任务。已开始的原生原子保存完成后再清理；取消发生在登记前则零任务登记、零请求。取消与登记竞态沿用已登记整批标记取消的规则。失败保留会话选择，只清理已确认无主的新资源。清理失败保留文件并报告，绝不自动重发。
- 关闭继续等待已接受提交、暂停后续发送并保留已经登记的任务；未提交会话选择随应用关闭消失。数据维护会重建工作区，因此存在仅会话选择时拒绝进入，并在排空已接受操作后再次检查；用户显式清空后才能维护。

## 旧数据、备份与异常恢复

不新增 Dexie 表、字段或偏好。绘图设置模块 v2、历史模块 v1、schema v8、备份文档 v5／信封 v1 保持；字段策略的 `DrawingDraft.references` 仍排除于可移植备份。旧字段继续由 `readDrawingDraftData` 纯克隆严格读取，初始化不清空、不自动迁移。提示词和参数写入保留旧绑定。只有显式移除、清空或替换选择，才持久释放不再保留的旧绑定；任务、成果、会话、提交或活动操作拥有的文件继续保留。新会话数据永不混入旧字段。私有备份恢复日志继续保护旧草稿绑定以便回滚。

新原生二进制导入在发布原图前写入私有 v1 恢复记录：`drawing/reference-imports/<scope>/<uuid>.json`，字段严格为 `version/reference/digest/size`。scope 由原生观察到的 Webview HTTP(S) origin 与固定数据库名 `AyaseStudio` 取 SHA-256，不接受前端指定源路径或来源。当前 Windows 正式版 `http://tauri.localhost` 与开发 origin 分开；opaque／未知来源拒绝。记录没有源文件路径、提示词或凭据，不导出、不备份。

启动先严格验证所有已存草稿／任务／成果的已知字段及资源所有权，再仅查看当前 scope 的有效恢复记录。只有已登记所有者不存在的记录才作为中断导入候选；删除前再次验证记录及原图大小／SHA。记录损坏、未来字段、来源不同或原图被改写时保留。裸原图目录不扫描删除，旧 Base64 导入无新记录，历史未知孤立文件保守保留。已有单实例与应用目录租约阻止同目录并发写入。本合同不把其他 origin 的空库存当作本库无主证明；普通 App 只使用固定 `AyaseStudio` 数据库。原生不识别任意前端数据库名称，其他数据库／测试必须使用独立应用 identifier，不可在同 origin 与资源根目录混用独立库存。本测量 identifier 内各临时库串行运行，完成清理后才进入下一库。

## 用户实测后的缩略图修正（2026-10-02）

用户随后确认重启开发环境后真实生成成功，并反馈滚动时历史缩略图及开始生成时参考图重载。本地确定性复现了两个原因：IntersectionObserver 离屏会回收 URL；新选择导入后 native 描述符 ID 替换了选择 ID，且预览分支从 Blob 切换为原生缩略图。单纯更新生成状态不造成重读。

修正为首次可见后保留当前卡片缩略图，离屏不回收，换源／卸载仍释放。提交升级只保留编辑器的选择 ID，不改变受管文件路径和任务所有权；已显示的 Blob 预览在当前卡片内绑定到首次受管路径，避免重新解码，换路径不复用。原 Blob 的内存寿命因此延长至卡片卸载或换源；它不进入持久记录。历史仍按 50 张分页，本次没有新增全局或磁盘缓存。切页后重新挂载仍可能重新读取。

回归先红后绿，覆盖滚出／滚回、升级 ID、重复提交后移除、换路径释放、生成状态更新、迟到响应和卸载。`npm.cmd run check` 通过（117 文件／1895 项测试、数据契约与生产构建）；独立增量审查无实质缺陷。隔离内置浏览器验证历史从视野外滚回后 URL 和缩略图读取计数不变，本地参考图提交前后 URL 相同，成果参考图再次生成的 URL 也相同；控制台无错误／警告。证据为 `.drawing110.local/thumbnail-check.log` 与 `thumbnail-cache-acceptance.jpg`。本轮不涉及 Rust、原生权限或网络合同变化，未重新发起真实服务请求；测试 Vite 使用独立 cacheDir，避免与用户开发服务共享依赖缓存。
