2026-10-01 用户授权规划并本地实施，随后明确授权提交、推送代码并关闭 #93。基于最新 #93、#94、#105；以下记录已实施的契约、验证证据和剩余接受项，远端交付结果见 #93 验收评论。

## 范围与契约

新导出使用文档 v5、信封 v1，继续严格读取 v1–v4。新增可选 `drawing` 区域，`settings` 与 `presets` 是否存在分别声明恢复范围；缺失不是空数据。新导出明确包含两类，预设空数组表示确实无预设。模块声明与内容存在性一致；旧 v4 的七模块集合保持原合同。

设置从当前草稿按字段策略投影：aspectRatio、resolution、modelId、openai.size／quality、count、concurrency、completionSound、reusedProtocol。历史缺失字段使用当前已确认默认值：auto／auto、空模型、OpenAI auto／auto、数量 1、并发 1、提示音开启。prompt、references、草稿身份、任务／批次／成果和图片不进入可移植区域。预设只有 id、name、content、createdAt、updatedAt；保留正文空白，不按同名合并。连接和 Key 沿用专用区域，普通绘图区域不带凭据。

本机读取、导出投影与备份读取复用纯克隆的绘图设置／预设读入口和 #105 可读性机制。设置模块 v1；无版本旧草稿按 v1 读取，不写回默认值。兼容未来版本只有声明可读时才过滤设置参数区；模型引用、协议、版本、资源、凭据和预设正文结构严格验证。过滤仅记路径，继续使用预览／结果／再导出警告和原始文件保留合同。

## 恢复策略与原子性

合并保留同 ID 预设、追加新 ID；副本分配新 ID；两者保留本机设置。替换只更新实际包含的类别：预设表可替换，设置仅补丁更新当前草稿设置，保留原 prompt、references 及其他本机字段。旧包／缺失类别不清空本机对应数据。没有本机草稿而需要设置时创建空 prompt、无参考图的当前草稿，不生成任务。

恢复沿用连接 ID 映射；绘图目标必须解析为绘图协议，失效时取消选择并报告，不猜测替代。保留的草稿／历史可能因全局连接替换失效，预览按冻结的供应商、连接、配置模型 ID、协议、地址和实际上游模型 ID 报告受影响项，不以显示名称判断、不改写历史。图片绑定不导出，预览说明需自行选择参考图。

可移植表清单与内部回滚快照分开：绘图草稿的原始本机内容只进入私有日志，预设也纳入同一次日志／Dexie 提交。旧日志没有绘图快照时回滚跳过该类别。任务、成果、绘图文件和未决绘图本地保存日志始终保留；资源恢复计划不产生 drawing 路径。

## 维护协调

继续采用重新加载的独占维护根。进入前同步封锁聊天与绘图命令，暂停绘图派发，等待既有提交、草稿／预设写入、参考图生命周期操作、导出／删除、本地保存。存在活动请求时提示先完成或由用户在原入口明确取消，不因备份自动中止。存在仅内存未保存图片时拒绝重载并提示先本地修复；不复用退出的放弃图片流程。准备失败释放门禁、保留数据和原队列暂停状态；成功进入后保留 queued 项，返回正常工作区按现有规则暂停。

原生备份启动围栏覆盖绘图文件操作锁，恢复顺序仍为备份日志回滚先于业务控制器与任何清理，之后由绘图既有初始化修复成果日志。直接维护入口和仓库调用保持一致性／日志校验；只在协调和回滚覆盖通过后移除旧“存在绘图就禁止”围栏。

## 纯文本容量样例

内置浏览器运行 5 轮，每轮 10,000 个显式预设、每条 450 字符正文，经过真实投影、JSON／摘要信封编码和校验解码；每轮核对恢复数量，未截断。每包 6,420,960 字节（约 6.12 MiB）。处理时间 797／747／745／730／735 ms，中位数 745 ms。

`performance.memory.usedJSHeapSize` 在各处理阶段采样的最大值为 186,616,300 字节（约 178 MiB），包含页面及此前轮次存活对象。它是浏览器采样最大值，不是瞬时精确峰值、增量内存或原生 WebView／整图库指标；该证据只覆盖本轮纯文本预算样例。128 MiB 文件、80 MiB 文档、8 MiB 非资源文本预算保持，超限拒绝而不截断。#94 继续单独测量图库／原生压力。

合成入口、配置和截图在忽略目录 `.drawing93.local/`；服务停止后可用端口 1493 重新启动 Vite 查看。它们不属于正式用户数据库或发布包。
